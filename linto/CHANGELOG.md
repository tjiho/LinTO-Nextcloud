# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.1] - 2026-09-20

### Added

- App store listing: full description, screenshots and their thumbnails

### Changed

- App icon is now the LinTO logo, in a light and a dark variant
- The Files action and the admin settings section use that icon, following the
  theme colour instead of a fixed one

## [1.0.0] - 2026-08-30

### Added

- Menu action on audio files for transcription
- Integration of LinTO transcript ui to open transcription
- Transcription editing bridge
